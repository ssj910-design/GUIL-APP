# 인수인계 — 카카오 알림톡 발신 IP 문제 (오라클 중계서버 설정)

**작성일**: 2026-08-05
**인수자**: 차호근

## 무슨 일이 있었나 (배경)

견적서를 카카오 알림톡으로 보내는 기능은 코드상으론 완성돼 있었는데, 실제 발송을 테스트해보니
알리고(Aligo) API가 에러를 냈다. 원인을 추적해보니 두 가지 문제가 순서대로 있었다:

1. **Vercel 환경변수에 알리고 인증 정보(`ALIGO_API_KEY` 등)가 아예 없었음** → 이건 이미 해결됨
   (신석주가 알리고 관리자 페이지에서 값 확인해서 Vercel에 5개 다 등록 완료: `ALIGO_API_KEY`,
   `ALIGO_USER_ID`, `ALIGO_SENDER_KEY`, `ALIGO_TEMPLATE_CODE`, `ALIGO_SENDER_PHONE`)
2. **알리고는 발송 서버 IP를 화이트리스트 등록해야만 호출을 받아준다** — 근데 Vercel은
   서버리스라 고정 IP가 없다. 알리고 CS에 문의했더니 "IP 제한은 보안상 해제 불가, 고정 IP를
   쓸 수 있는 다른 서버를 쓰라"는 답변을 받음(아래에 CS 답변 원문 있음).

그래서 **고정 IP를 가진 작은 중계서버**를 하나 두고, Vercel은 알리고를 직접 호출하는 대신
이 중계서버를 거치도록 설계했다. 무료로 하려고 **오라클 클라우드 Always Free** 인스턴스를
쓰기로 했다(월 비용 0원, 대신 계정이 가끔 예고 없이 정지되는 사례가 있다는 리스크는 있음 —
그래서 나중에 문제 생기면 유료 VPS로 갈아탈 수 있게 설계해뒀다, 아래 참고).

### 알리고 CS 답변 원문
> API 사용 시 고정 IP 만을 허용하는 이유는 해킹시도를 방지하기 위해서 API 요청자를 고정IP로
> 제한하고 있으며, 유동IP를 허용할경우 요청자를 보증할수 없기 때문에 반드시 고정 IP 를
> 사용하셔야 합니다. IP 고정을 할 수 없는 상황이라면, 고정 IP를 할당할 수 있는 다른 서버를
> 이용하시는 방법이 있습니다. 혹은 해당 서비스에서 고정IP로 세팅하여서 발송하는 방법 이외에는
> 이용 방법이 없는 점 양해 부탁드립니다.

## 코드는 이미 다 준비돼 있음

- `relay-server/server.js` — 중계서버 코드. **순수 Node.js, 외부 패키지 의존성 전혀 없음**
  (오라클이든 다른 VPS든 `node server.js`만 실행하면 그대로 동작).
- `relay-server/README.md` — 오라클 인스턴스 만드는 것부터 서버 실행, 알리고 IP 등록,
  Vercel 환경변수 설정까지 **1~8번 단계별로 다 적혀 있음**. 이 인수인계 문서는 배경 설명이고,
  실제 작업은 그 README를 따라가면 된다.
- `lib/alimtalk.js` — `ALIMTALK_RELAY_URL` 환경변수가 설정돼 있으면 알리고 대신 중계서버를
  호출하도록 이미 수정 완료. 이 환경변수가 없으면 기존처럼 알리고를 직접 호출한다(그럼 IP
  에러가 나는 게 정상 — 아직 중계서버가 없다는 뜻).

전부 커밋·푸시 완료(main 브랜치, 커밋 `1d56967`).

## 다 끝나면 어떻게 확인하나

Vercel에 `ALIMTALK_RELAY_URL`, `ALIMTALK_RELAY_SECRET` 두 개 추가하고 재배포한 뒤,
견적 발송 화면에서 카카오 알림톡 체크박스로 실제 견적 하나 보내보면 된다. 혹시 확인 방법
모르겠으면 이 세션(Claude Code)에서 010-2939-2431로 테스트 발송해주는 것도 가능하니
물어보면 됨.
