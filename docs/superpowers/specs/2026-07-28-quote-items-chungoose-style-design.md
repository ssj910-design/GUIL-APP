# 견적 품목편집 — 청구스 스타일 품목 테이블 + 할인정보 (1단계) 설계

## 배경

경쟁 서비스 청구스(chungoose.ai)의 견적서 작성 화면 스크린샷을 참고해, 우리 관리자웹의
`QuoteItemsModal`(견적 품목편집) 입력 경험을 그와 비슷하게 다듬는다. 청구스 전체 구성(공급자/
고객 정보 2단 레이아웃, 안내메시지 리치텍스트, 첨부파일 드래그드롭, 실시간 미리보기 등)은
범위가 커서 여러 단계로 나누기로 했고, 이번 1단계는 **품목 테이블 구조와 부가세/할인 계산**에
한정한다.

**중요한 제약**: 실제로 발송되는 PDF 견적서(`lib/quotePdf.js`)는 회사 정식 서식(사업자등록번호,
자재비/인건비/운반비/안전관리비/이윤 5개 항목 구조, 소계(1+2+3+4+5), 폐부품 무상수거 조항 등)이
하드코딩되어 있고 **이번 작업으로 건드리지 않는다**. 이번 변경은 **관리자가 입력하는 화면**에만
적용되고, 저장되는 데이터 형태(`quote_items` 배열의 `category`/`name`/`unitNo`/`spec`/`unit`/
`qty`/`unitPrice`, 그리고 `transport_cost`/`safety_cost`/`profit` 별도 컬럼)는 지금과 동일하게
유지한다.

## 1. 품목 테이블

기존 컬럼(품명/호기/규격/단위/수량/단가)은 그대로 두고, 다음을 추가한다:

- **공급가액** (자동계산, 읽기전용) = 단가 × 수량
- **세액** (자동계산, 읽기전용) = 공급가액 × 10% (부가세 별도 고정 — PDF도 항상 "VAT별도"로
  표기하므로 옵션 선택 없이 고정값으로 계산만 보여준다)
- **합계** (자동계산, 읽기전용) = 공급가액 + 세액
- 각 행에 **순서변경 화살표**(위/아래) 추가 — 같은 구분(자재비 또는 인건비) 안에서만 순서를
  바꿀 수 있다(구분을 넘나드는 이동은 지원하지 않음 — PDF가 구분별로 섹션을 나눠 그리므로,
  구분을 넘나드는 순서변경은 실질적으로 "구분 변경"과 같은 의미가 되어 혼란을 만든다).
- 기존처럼 자재비/인건비 구분(섹션 헤더 + "품목 추가" 버튼)은 그대로 유지한다.

## 2. 운반비 / 안전관리비 및 기타 / 이윤

현재는 품목 테이블과 별개로 숫자 입력칸 3개(운반비, 안전관리비 및 기타, 이윤)가 따로 있다.
이를 **품목 테이블 맨 아래 고정 3줄**로 바꾼다:

- 품목명은 잠겨 있다(수정·삭제·순서변경 불가) — "운반비", "안전관리비 및 기타", "이윤" 3줄
  고정.
- **단가** 칸만 입력 가능. 수량은 항상 1로 고정되어 공급가액이 단가 값 그대로 나온다.
- 나머지 컬럼(세액/합계)은 일반 품목 행과 같은 계산식을 그대로 적용해 시각적으로 통일한다.
- 저장 시에는 지금처럼 이 3줄의 단가 값이 각각 `transport_cost`/`safety_cost`/`profit`
  컬럼에 들어간다(데이터 흐름 변경 없음, 입력 UI만 통일).

## 3. 할인 정보 (신규 섹션)

품목 테이블 아래에 새 섹션 추가:

- **할인율(%)** 입력 또는 **할인금액(원)** 입력 — 하나를 입력하면 다른 하나는 그 값 기준으로
  자동 계산되어 함께 표시된다(할인율 입력 시 할인금액 = 소계 × 할인율/100, 할인금액 직접 입력
  시 할인율 = 할인금액 / 소계 × 100).
- **최종금액** = 소계(기존 자재비+인건비+운반비+안전관리비+이윤 합) − 할인금액. 화면에 표시.

**이번 1단계에서는 화면 표시 전용이다** — 실제 PDF 생성이나 `quote_requests` 저장 데이터에는
전혀 반영되지 않는다(사용자 확인 완료). 모달을 닫거나 "발행 확정"을 눌러도 할인 입력값은
저장되지 않고 사라진다. 나중에 필요해지면 이윤 줄 금액에 할인을 반영하는 식으로 확장할 수
있다 — 이번 범위 밖.

## 범위 밖 (이후 단계에서 다룰 것)

- 공급자/고객 정보 2단 레이아웃 (담당자 선택 + 참조인 안내문구)
- 기본정보 확장(부가세 옵션 선택, 유효기간, 견적안 추가 — 여러 견적 변형)
- 비고 / 안내메시지(리치텍스트 에디터) / 첨부파일(드래그드롭)
- 이메일 제목/머리글 직접 편집
- 실시간 미리보기 패널
- PDF 견적서 양식 자체의 구조 변경(이번엔 그대로 유지)
