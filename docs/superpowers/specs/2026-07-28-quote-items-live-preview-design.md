# 견적 품목편집 실시간 미리보기 (4단계) 설계

## 배경

청구스(chungoose.ai) 참고 4단계 — 품목편집 모달(`QuoteItemsModal.jsx`)에서 품목·금액을
입력하는 동안 오른쪽에 견적서 요약 미리보기가 실시간으로 같이 업데이트되게 한다.

**중요한 제약**: 실제 PDF 견적서(`lib/quotePdf.js`)는 회사 정식 서식(로고, 사업자정보,
자재비/인건비 구분, 특이사항 조항)을 pdf-lib로 직접 그리는 복잡한 렌더러라, 이걸 그대로
실시간으로 다시 그리는 건 렌더링 로직을 두 곳에 중복 관리하는 부담이 크다. 이번 미리보기는
**PDF 서식을 그대로 재현하지 않는 간단한 카드형 요약**이다 — 새 렌더링 로직 없이, 이미
계산되고 있는 값(품목별 소계, 전체 소계/합계, 할인 최종금액)을 카드로 다시 보여주기만 한다.
PDF 생성·저장 로직("발행 확정" 버튼)은 이번에도 그대로 유지한다.

## 1. 레이아웃

모달을 2열로 재구성한다: 왼쪽엔 지금 있는 입력 폼(기사 요청 원본 참고 · 기본정보 · 품목
테이블 · 운반비/안전관리비/이윤 고정 3줄 · 소계/합계 박스 · 할인 정보)을 그대로 두고,
오른쪽에 새 "미리보기" 카드를 추가한다. 입력 폼 쪽 값이 바뀔 때마다 미리보기도 같이
다시 계산되어 보인다(별도 상태 없이 기존 state를 그대로 읽어서 렌더링).

모달 폭은 이미 `wide="2xl"`(매우 넓음)이라 2단 구성에 무리가 없다.

## 2. 미리보기 카드 내용

- 타이틀: "견적서"
- 공급자: 회사명(`lib/company.js`의 `COMPANY.name`)
- 고객: 현장명(`site?.name ?? quote.siteName`)
- 견적번호 / 견적일 (지금 입력 중인 `quoteNumber`/`quoteDate`)
- 품목 목록: 자재비/인건비 구분 없이 하나로 합쳐서 한 줄씩 — 품명 · 수량 × 단가 = 금액.
  운반비/안전관리비/이윤도 값이 0보다 크면 같은 목록에 포함(구분 라벨 없이 그 이름 그대로
  한 줄).
- 소계 / 합계(VAT별도, 천단위 절사) — 기존 계산값 그대로.
- 할인을 입력했으면(할인금액 > 0) 최종금액도 추가로 표시.

## 3. 범위 밖

- PDF 서식(로고, 회사 사업자정보, 자재비/인건비 구분, 특이사항 조항) 재현 — 안 함.
- 미리보기 데이터의 별도 저장 — 안 함(화면 표시 전용, 기존 state 재사용).
- PDF 생성/저장 로직 변경 — 없음.
