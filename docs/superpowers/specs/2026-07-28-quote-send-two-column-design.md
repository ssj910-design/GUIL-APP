# 견적 발송 공급자/고객 정보 2단 레이아웃 (2단계) 설계

## 배경

청구스(chungoose.ai) 견적 작성 화면 참고 1단계(품목 테이블)에 이어, 이번엔 견적 발송
모달(`QuoteSendModal.jsx`)을 청구스처럼 "공급자 정보 | 고객 정보" 2단 레이아웃으로 바꾼다.
청구스는 각 담당자를 드롭다운으로 고르지만, 우리는 이미 현장담당자(`siteManagers`)와
직원(`profiles`) 데이터가 있으므로 그 목록에서 고르는 드롭다운을 추가하고, 기존 자유입력
필드(받는사람 이메일/전화, 발신측 CC 이메일, 참조인 이메일/전화)는 그대로 남겨 드롭다운이
그 값을 채워주는 "선택기 + 직접수정 겸용" 방식으로 만든다. 새 담당자를 이 모달에서 바로
등록하는 기능(수정/추가 버튼)과 "사업자/개인" 고객유형 토글은 이번 범위에서 제외한다.

## 1. 레이아웃

`QuoteSendModal`을 2열 그리드로 재구성:

**왼쪽 — 공급자 정보**
- 회사명: "구일엘리베이터(주)" (읽기전용)
- 주소: `lib/quotePdf.js`의 `COMPANY.address`를 그대로 가져와 표시 (읽기전용 — PDF와 같은
  주소를 이중 관리하지 않도록 `COMPANY` 상수를 export해서 재사용)
- 담당자: `profiles` 드롭다운(이름순 정렬). 선택하면 **실제 발송되는 이메일/카카오 본문의
  서명이 바뀐다** (아래 3번 참고). 기본 선택값은 이름이 정확히 "신석주"이고 전화번호가 있는
  프로필(현재 하드코딩된 서명과 동일 인물) — 없으면 미선택.
- 참조(CC) 이메일: 기존 "발신측 CC 이메일" 텍스트 입력은 그대로 두고, 그 위에 이메일이 등록된
  `profiles` 드롭다운을 추가 — 고르면 텍스트 입력에 그 이메일이 채워지고, 이후 직접 수정도
  가능(드롭다운은 채워주기만 함, 실제 전송 값은 여전히 텍스트 입력의 값).

**오른쪽 — 고객 정보**
- 담당자(받는사람): 이 견적의 현장(`siteManagers`, 대표 담당자가 기본 선택) 드롭다운 — 고르면
  기존 "받는사람 이메일"/"받는사람 전화번호" 텍스트 입력에 값이 채워지고, 이후 직접 수정 가능.
- 참조인: 같은 현장의 **다른**(대표 담당자 제외) `siteManagers` 드롭다운 — 고르면 기존
  "참조인 이메일"/"참조인 전화번호" 텍스트 입력에 값이 채워지고, 이후 직접 수정 가능.

두 드롭다운·텍스트입력 쌍 모두, 후보 목록에 원하는 사람이 없으면 그냥 텍스트 입력에 직접
타이핑하면 된다(드롭다운은 편의 기능일 뿐 필수 아님).

## 2. 데이터 소스

- 공급측 담당자 후보: `profiles`(전 직원, 관리자 콘솔이 이미 로드해둔 데이터) — 새 쿼리 없음.
  `MaterialsAdmin.jsx`가 `QuoteSendModal`에 새 prop `profiles={data.profiles ?? []}` 전달.
  퇴사자(`deleted_at` 있음) · 비활성(`is_active === false`) 직원은 두 드롭다운(담당자, 참조)
  후보에서 제외한다.
- 고객측 담당자 후보: 이미 전달되고 있는 `siteManagers` prop 그대로 사용 — 변경 없음.

## 3. 서명 반영 (공급측 담당자 선택의 실질 효과)

지금 `lib/email.js`의 `buildBody`와 `lib/alimtalk.js`의 `buildMessage`는 서명 줄이
`"견적 담당: 신석주 차장(010-2939-2431)"`로 하드코딩되어 있다. 이걸 선택된 담당자의
이름/전화번호로 바꾼다:

- 두 함수 모두 `(quote, supplierName, supplierPhone)`을 받도록 시그니처 변경. 서명 줄을
  `` `견적 담당: ${supplierName}(${supplierPhone})` ``로 바꾸되, 둘 다 없으면(직원 프로필에
  전화번호가 없거나 선택 안 한 경우) 지금 문구인 `"견적 담당: 신석주 차장(010-2939-2431)"`을
  그대로 폴백으로 쓴다.
- **직함("차장") 제거**: `profiles` 테이블엔 직함 컬럼이 없어서, 다른 사람을 고르면 "차장"이
  틀린 직함이 된다. 폴백이 아닌 실제 선택값을 쓸 땐 직함 없이 `이름(전화번호)` 형식으로
  통일한다.
- `/api/send-quote/route.js`가 요청 바디에서 `supplierName`/`supplierPhone`을 받아
  `sendQuoteEmail`/`sendQuoteAlimtalk` 호출에 그대로 전달.
- `QuoteSendModal`은 선택된 공급측 담당자 프로필의 `name`과 (`phone` 없으면 `tel`)을
  `supplierName`/`supplierPhone`으로 발송 요청 바디에 실어 보낸다.

## 범위 밖

- 드롭다운 옆 "수정"/"추가" 버튼(새 담당자를 이 모달에서 바로 등록) — 제외, 필요하면 기존
  인사관리/현장정보 화면에서 등록.
- "사업자/개인" 고객 유형 토글 — 우리 데이터에 그 구분이 없어 제외.
- 회사명/주소 편집 — 읽기전용 유지(PDF의 `COMPANY`와 동일 소스).
