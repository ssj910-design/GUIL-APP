# 솔라피 알림톡 세팅 (2026-08-05, 알리고→솔라피 전환)

> 전환 이유: 알리고는 고정 IP 필수 → Vercel 직접 호출 불가 → 중계 서버 필요.
> 솔라피는 API 키 인증(IP 무관) → Vercel에서 바로 발송, 중계 서버 불필요.
> 코드는 `lib/alimtalk.js` 교체 완료. **키·시크릿 값은 절대 이 문서/저장소에 적지 말 것.**

## 진행 체크리스트

- [x] 솔라피 가입 + API 키 발급 (모든 IP 허용 — Key/Secret 인증이라 안전)
- [ ] **카카오 채널 연동** — 콘솔 → 카카오 채널 연동 → 구일 카카오톡 채널을 발신프로필로 등록
      (채널 관리자 휴대폰 인증 필요) → 완료되면 **pfId** 확인
- [ ] **알림톡 템플릿 등록·심사** — 아래 문안 그대로 등록 → 심사 요청 (1~3일)
      → 승인되면 **templateId** 확인
- [ ] (대체발송 쓰려면) 콘솔에 **발신번호 등록** — 알림톡 실패 시 SMS 자동 대체용
- [ ] Vercel 환경변수 등록 (친구 쪽 — HANDOFF 참조) 후 재배포
- [ ] 테스트 발송 1건 → 확인되면 알리고 환경변수 5개·relay-server/ 정리

알리고에서 승인받았던 문안과 동일 내용. 변수는 `#{변수명}` 형식.

```

안녕하세요, #{현장명} 고객님.
안전하고 원활한 승강기 운행을 위해 아래 부품 교체 관련 견적서를 발송해 드립니다.

■ 견적일: #{견적일}
■ 특이사항: #{특이사항}

아래 버튼을 눌러 견적서 확인 후 승인(회신)해 주시면, 부품 수급 및 일정을 조율하여 신속하고 안전하게 교체 공사를 진행하도록 하겠습니다.

늘 안전을 최우선으로 꼼꼼하게 관리하겠습니다. 감사합니다.

견적 담당:
신석주 차장(010-2939-2431)

※ 이 메시지는 승강기 유지보수 계약에 따라 부품 교체가 필요한 경우 발송됩니다.
```

**버튼**: 웹링크(WL) · 이름 "견적서 확인하기" · Mobile/PC 링크: `https://#{link}`

## 환경변수 (이름만 — 값은 안전한 경로로)

| 이름 | 값 출처 |
|---|---|
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | 콘솔 API Key 발급 화면 |
| `SOLAPI_PF_ID` | 채널 연동 완료 후 발신프로필 상세 |
| `SOLAPI_TEMPLATE_ID` | 템플릿 승인 후 템플릿 상세 |
| `SOLAPI_SENDER_PHONE` | 등록한 발신번호 (대체발송 안 쓰면 비워둠 — 그럼 알림톡만 감) |

로컬은 `.env.local`에 등록 완료(키 2개). Vercel은 5개 전부 — 알리고 5개(`ALIGO_*`)와
`ALIMTALK_RELAY_URL/SECRET`은 테스트 성공 후 삭제.
