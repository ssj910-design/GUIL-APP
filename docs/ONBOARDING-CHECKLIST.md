# 타사 온보딩 체크리스트 — 고객사에게 받을 것 (2026-08-04)

> 컨시어지 온보딩(MULTITENANT-PLAN 5-5) 때 상담~세팅 단계에서 수집할 목록.
> "어디에 쓰이나"는 현재 코드 기준 — 항목이 늘면 여기에 추가.

## 1. 계약·회사 기본 (상담 단계)

| 항목 | 필수 | 어디에 쓰이나 |
|---|---|---|
| 사업자등록증 사본 | 필수 | 우리와의 이용 계약 + 견적서·청구서에 회사정보 표기 |
| 회사 정식 명칭(법인명) | 필수 | 앱 헤더·문서 발행 (`tenants.name`) |
| 로고 파일 (PNG, 투명배경 권장) | 옵션 | 로그인·헤더 (`tenants.logo_url`) — 없으면 회사명 텍스트 |
| 대표전화·주소 | 필수 | 견적서 발행, 고객 안내문자(문자 기능 붙일 때) |
| 계약 담당자(대표 or 실무) 연락처 | 필수 | 온보딩 진행 + 관리자 계정 전달 대상 |

## 2. 시스템 인증키 (세팅 단계 — 발급 주체 주의)

| 항목 | 필수 | 발급 주체 | 어디에 쓰이나 |
|---|---|---|---|
| **승강기민원24 공유플랫폼 인증키+암호화키** | 자체점검 자동제출 쓰면 필수 | **고객사가 승강기안전공단에 신청** (유지관리업체 명의로만 발급됨 — 우리가 대신 못 받음, 신청 방법은 안내 가능) | 자체점검 공단 자동 제출 (`MINWON24_CERT_KEY/CRYPT_KEY` — 현재 구일 것 하드코딩 → 테넌트별 저장으로 전환 필요) |
| 회사 메일 계정 (SMTP 앱 비밀번호) | 견적 메일 쓰면 필수 | 고객사 (네이버 등) | 견적서 이메일 발송 — 또는 중앙 발송 서비스(Resend)로 대체 검토 중 (MULTITENANT-PLAN 5-3) |

**받을 필요 없는 것 (우리 플랫폼 공용키)**: Supabase, 푸시(VAPID/FCM), T맵, 국가승강기정보센터 실시간조회(data.go.kr) — 전부 우리 키 하나로 전 테넌트 커버.

## 3. 직원 정보 (엑셀 양식 하나 주고 받기)

| 항목 | 필수 | 어디에 쓰이나 |
|---|---|---|
| 직원 명단: 이름·역할(관리자/기사)·연락처 | 필수 | profiles 생성 + 계정 발급 |
| **기사별 승강기민원24 점검자 ID** | 자체점검 쓰면 필수 | 공단 제출 시 SELCHK_USID — 없는 기사는 제출 불가 |
| 입사일 | 권장 | 연차 자동 계산 |
| 당직 순번 (쓴다면) | 옵션 | 워크캘린더 근무표 |

## 4. 현장 데이터 (엑셀 — 검증 퍼널로 임포트)

| 항목 | 필수 | 비고 |
|---|---|---|
| **승강기민원24 현장관리 엑셀** (센터에서 다운로드) | 필수 | 현장·호기·승강기고유번호·검사일의 기준 원본 |
| 자체 관리 엑셀 (있는 그대로) | 권장 | 계약일·담당자·메일·비밀번호 등 — 지저분해도 검증 퍼널이 소화 (구일 때 779행 실전 검증됨) |
| 비상통화장치 번호 목록 | 옵션 | 전용 업로드 도구 있음 |
| 현장별 열쇠위치·출입 비밀번호 | 옵션 | 갇힘 구조 시간 단축 — 현장 접근정보 컬럼 |
| 담당기사 배정표 (현장↔기사) | 필수 | 없으면 자체 엑셀의 "점검자" 열로 대체 |

## 5. 세팅 완료 후 우리가 전달하는 것

- 접속 URL + 관리자 초기 계정 (비번 1234, 첫 로그인 시 강제 변경)
- 직원 아이디 목록 (관리자가 각 직원에게 전달)
- 기기 등록(푸시 알림 켜기) 안내문 — 아이폰은 홈 화면 추가 필수. ※ 구일에서 얻은 교훈: **이걸 온보딩 때 같이 안 하면 4/20명 꼴로 알림 못 받는 상태가 됨** — 세팅 방문 시 전 직원 폰에서 직접 확인하는 게 최선

## 미확정 (붙일 때 결정)

- 문자(SMS) 발송 — 기능 자체가 미구현. **방식은 확정(2026-08-04, eleva-app/docs/pages/failure.md)**:
  발신번호 = 회사 대표번호(사전등록제), SMS 업체 계약은 플랫폼 1개, 테넌트는 대표번호 등록 서류만
  (통신서비스 이용증명원 등 1회). 쓰기로 한 회사만 수집 항목에 추가: **대표번호 + 등록 서류**
- 테마색 — 화이트라벨 2차 (로그인 화면설계 6장 ④)
