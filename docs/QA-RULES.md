## 1. 기사 로그인
파일: `LoginScreen.jsx`, `ElevatorFieldApp.jsx`(handleLogin), RPC `verify_login`(마이그 067)

**역할**: 기사(role=engineer). ※ 관리자 로그인·최고/중간관리자는 별도 항목으로.

**필요 요소**
- `profiles`: role=engineer, **login_id 있음(=민원24 아이디)**, is_active=true, deleted_at=null
- `user_secrets`: 그 프로필의 비번 해시(초기 `1234`, must_change=true)
- **login_id가 활성·미삭제 프로필 중 유일**해야 함 (중복이면 로그인 자체가 실패 — count≠1)
- (전제) `SKIP_LOGIN=false` 여야 로그인 화면이 뜬다 — **지금은 꺼져 있음**(로그인 미가동)

**정상 흐름**
아이디+비번 입력 → `verify_login` RPC(해시 검증, 해시는 클라로 안 나옴) → 세션 저장(`guilAuthV1`) → must_change면 **강제 비번변경** → 앱 진입

**QA 체크포인트 (조심할 부분)**
1. **중복 login_id** → 둘 다 로그인 실패. 기사 민원24 아이디가 관리자 login_id와 겹치면 사고 (과거 guil238684 중복 사례 있었음)
2. **login_id 없는 기사**(민원24 아이디 미등록) → 로그인 불가 (백필이 민원24 아이디 있는 기사만 채웠음)
3. **user_secrets 없는 신규 기사** → "아이디/비번 틀림"으로 표시됨(실은 비번 미설정) → 신규 등록 시 **1234 시딩 필수**
4. **대소문자·공백 민감** — verify_login은 정확히 일치. 저장은 trim만 (autoCapitalize off)
5. **실패 메시지가 하나뿐** ("아이디 또는 비밀번호가 올바르지 않습니다") → 원인(오타/중복/미설정/비활성/삭제) 구분 안 됨. 보안엔 좋지만 디버깅 땐 DB 직접 확인
6. **must_change 강제변경이 새로고침해도 반복 안 되는지** (앱·콘솔 둘 다 최근 수정 완료 — 회귀 주의)
7. **아이디 저장**: 체크 시 프리필+체크복원, 해제 시 삭제. **비번은 저장 안 함**
8. **퇴사/비활성 기사 차단**되는지 (is_active, deleted_at)

**구일전용 → 타사 일반화 (화이트라벨)**
1. **login_id = 민원24 아이디**는 구일/국내 전용 → 타사는 login_id를 민원24와 분리한 일반 아이디로. ※ 067에서 이미 login_id를 minwon_id와 **분리**해둠 — 구조는 준비됨
2. **login_id 유일성이 전역** → 멀티테넌트는 **테넌트별 유일**(`unique(tenant_id, login_id)`)로, `verify_login`도 tenant로 스코프
3. **로그인 시 테넌트 구분 필요** — 전역 유일 아이디로 프로필→테넌트 유도하거나, 회사 서브도메인/회사코드 입력 (미확정)
4. **화면 제목 "구일엘리베이터(주)" 하드코딩**(LoginScreen) → `tenant.name`
5. **초기 비번 1234** 정책은 테넌트별 설정 가능(미확정)

"위치 다시 받기" 버튼이 그대로 보였다(수집은 안 하는데 안내만 남은 상태 — 사용자 혼란).
`LOCATION_TRACKING` 조건을 5곳에 추가해 해소. **교훈: 기능을 끌 땐 그 기능을 설명하는 UI도 같이 꺼야 한다.**

**되살리는 조건** — 로그인 3단계(SKIP_LOGIN=false)와 함께:
1. 첫 로그인 시 **위치정보 수집·이용 동의** 화면 (목적·항목·보유기간·거부권·거부 시 불이익 없음 명시)
2. 개인정보/위치정보 처리방침 — **T맵(SK텔레콤) 위탁** 명시 (출발·도착 좌표 전달, 미보관)
3. `LOCATION_TRACKING = true`
※ 설계 자체는 이미 요건에 가깝다 — 근무 중에만·최신 1건만 보관(이력 미적재)·개인이 끌 수 있음.
※ **Eleva(타사 SaaS)는 별도 문제**: 위치기반서비스사업 신고 대상 여부를 영업 전 확인해야 한다.
