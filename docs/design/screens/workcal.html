워크캘린더 v0.1

화면설계서 · 코드 WorkCalendarSheet.jsx · 당직·숙직 근무표 + 연차 신청 · ← 설계 허브

1. 이 화면의 정체 — 근무 일정의 단일 창구

  • 당직·숙직 근무표(순번 기반)와 연차 신청·잔여·내역이 한 화면 — 마이페이지의 연차 기능이 여기로 이동해 옴
  • 홈의 워크캘린더 미리보기 스트립이 이 화면의 축약판
  • 근무 교환: 기사끼리 요청→수락 (교환 요청·결과 알림 2종)

2. 하위 2탭

탭핵심 규칙
당직·숙직월 근무표(이름 옆 숫자 = 순번). 근무 조정(교환) 요청. 전날 18:00에 "내일 내 당직" 알림(pg_cron)
연차신청 기간에 본인 당직·숙직 끼면 차단 — "근무 교환 먼저" 안내. 입사일 기준 연차 자동 계산(yearsOfService). 승인·반려 알림

4. QA 체크포인트 — 2026-08-04 검증 (QA-RULES 7장)

  1. ✅ 연차-당직 충돌 차단 (소프트 종류는 "관리자 재배정 필요" 안내로 통과)
  2. ✅ 교환 요청→수락→근무표 반영 + 알림 2종

6. 화이트라벨 — 구일전용 → 타사 일반화
