1. 콘솔 공통 규칙

  • v2 네이티브: FK(unit_id 등) 기반, 옛 컬럼 참조 금지 (편집이 겹치면 syncLegacy로 옛 컬럼 병행 갱신)
  • 셸이 전 테이블을 한 번에 로드해 props로 배분 — 새 화면은 admin/에 파일 추가 + MENU 연결
  • 권한: 최고관리자만 설정 메뉴. 자재담당관리자는 콘솔 접근 불가(모바일 관리자 모드만)
  • 콘솔에서의 쓰기 동작도 기사 폰에 알림 — notify 연결 (7/29 구멍 메움)
