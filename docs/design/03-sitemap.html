1. 모바일 앱 화면 트리

  • 로그인 — SKIP_LOGIN=false일 때만. 첫 로그인이면 강제 비밀번호 변경 화면
  • 하단 탭 (9개)
    • 홈 — 출근 체크, 처리현황 요약, 집중관리 현장, 실시간 검사, 내 할일·당직. 고장 카드는 고장접수 탭과 공유
    • 현장정보 — 현장 목록·검색 → 현장 상세(호기·담당자·계약·사진) → 승강기(호기) 상세
    • 고장접수 — 접수 폼(4단계 스텝), 미배정/진행중/완료 카드, 출동 응답·도착·처리결과
    • 자체점검 — 월별 점검 계획·수행·기록 (공단 제출 체계), 점검항목 체크
    • 검사관리 — 국가승강기정보센터 연동: 검사 도래 현장, 조건부/불합격 상세
    • 자재·견적 — 자재신청 / 견적요청 / 상비부품(재고·보충) 3개 서브탭, 신청 상세 시트
    • 비용청구 — 부품교체·공사 청구 작성(사진 전/후), 청구 내역
    • 할일관리 — 자재 교체·시공 확인 할일 (지급완료 시 자동 생성), 재배정 요청
    • 워크캘린더 — 당직·숙직 근무표, 근무 교환, 연차 캘린더·신청
  • 플로팅 버튼 (모든 탭 위)
    • 게시판 — 글·댓글·사진·좋아요, @멘션, 공지 등록. 연필 FAB로 글쓰기. 알림을 누르면 그 글로 바로 이동
    • 관리자 모드 퀵버튼 관리자만 — 게시판 FAB 위에 표시
      • 관리자 모드 (모바일) — 처리대기 요약 대시보드, 자재 출하·견적·상비·재배정 요청 처리(아코디언+스와이프), 할일·비용청구 화면 재사용
  • 헤더 (우상단)
    • 알림 — 안읽음 배지, 알림 목록
    • 마이페이지 — 프로필·다가오는 근무·알림 설정(기기 푸시 스위치+종류별)·비밀번호 변경·건의하기·위치 공유·로그아웃

2. PC 관리자 콘솔 화면 트리 (/admin)

  • 관리자 로그인 — role=admin만 통과. 첫 로그인이면 강제 비밀번호 변경
  • 사이드바 메뉴 (13개)
    • 대시보드 — 오늘 처리할 것(승인대기 큐), 실시간 고장 현황, 고장 접수·배정, 기사 위치 지도(관제), 출근 현황, 30일 초과 미청구 KPI
    • 현장정보 — 현장·호기·담당자·계약 관리, 설치장소, 엑셀 일괄등록·검증 업로드·비상통화 번호 업로드, 계약 필터(운영/만료임박/종료), 지도 모달
    • 고장관리 — 전체 고장 표, 접수(스텝 폼)·배정·재배정, 상세
    • 에러코드집 — 고장구분·에러코드 사전
    • 검사관리 — 검사 일정·결과, 공단 데이터 캐시
    • 자재·견적 신청내역 — 자재/견적/상비 승인·지급완료(할일 자동 생성), 신청 취소, 견적 발행·이메일/알림톡 발송(발송 이력)
    • 부품교체·공사 내역 — 비용청구 검토. 무상 처리·가격 조정 최고관리자만
    • 할 일 관리 — 전체 할일, 배정·재배정 요청 처리
    • 자체점검 현황 — 월별 진행률, 점검 기록 열람
    • 게시판 — 모바일 게시판의 웹 버전 (글·공지·@멘션·댓글)
    • 인사관리 — 하위 탭: 직원(등록·수정) / 연차(승인·차감) / 워크캘린더. 관리자 등록·비번 초기화·당직표 생성 최고관리자만
    • 통계 — 고장·처리 통계 (구일 전용 문구 있음 → 화이트라벨 대상)
    • 알림 설정 최고관리자만 — 회사 알림 정책 27종(켬/끔·등급·받는 관리자 등급 지정·테스트 발송) — 개인 설정보다 우선
  • 사이드바 하단 — 내 이름·등급, 비밀번호 변경, 로그아웃

3. 화면 간 이동 규칙

  • 모바일: 하단 탭 = 큰 이동 / 탭 안에서 목록 → 상세는 드릴다운(뒤로가기) / 게시판·관리자모드는 플로팅 버튼 / 알림 탭하면 관련 화면으로 이동
  • 교차 참조 3곳 (코드 공유): 홈 ↔ 고장접수(고장 카드·모달 공유) / 관리자모드 → 할일관리 화면 / 관리자모드 → 비용청구 내역 화면. 더 늘리지 않는 게 규칙 (컴포넌트 규칙 문서)
  • 같은 데이터, 두 화면: 게시판(모바일=콘솔), 고장(모바일 카드=콘솔 표), 자재(모바일 신청=콘솔 처리) — 한쪽에서 바꾸면 다른 쪽도 같은 DB를 봄

4. 다음 단계 — 화면설계서(screens/)와 연결

위 트리의 화면 하나마다 screens/에 1페이지(스크린샷+요소 주석+QA+화이트라벨)를 만든다. 순서는 유저플로우 중요도: 로그인 → 홈 → 고장접수 → 관리자 대시보드부터. (docs/QA-RULES.md의 로그인 항목을 첫 페이지로 흡수)
