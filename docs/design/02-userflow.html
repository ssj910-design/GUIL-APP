유저플로우 v0.3

2026-07-30 · 실제 앱 동작 기준 3개 흐름 · ← 설계 허브로

기사현장요원이 하는 행동 관리자중간·최고관리자 자동앱·서버가 스스로 (알림·크론·자동생성) 고객건물 담당자·신고자

흐름 1. 기사의 하루

기사앱 열기 → 출근 체크 위치는 선택 — 허용하면 좌표 기록(가까운 현장 우선 배정에 사용), 미허용이어도 출근 됨(강제는 위법)
기사오늘 할 일 확인 (홈탭) 배정된 고장 / 이달 자체점검 계획 / 할일(자재 교체·시공 확인) / 오늘 당직 여부
기사현장 업무 반복 고장 출동·처리 (→ 흐름 2), 자체점검 수행·기록, 검사 대응
기사현장에서 부품이 필요해지면 자재신청(사진 포함) 또는 견적요청 / 상비부품 쓰면 재고 자동 차감 + 보충 신청 알림 → 관리자: 자재·견적 신청 들어옴
기사게시판·알림 확인 공지·멘션 확인, 필요하면 글·댓글. 연차 신청·근무 교환은 워크캘린더에서
기사근무 종료 17:30 이후 종료 버튼 강조. 당직·숙직이면 그 버튼이 자동으로 뜸 — 숙직은 다음날 아침 마감

흐름 2. 고장 한 건의 일생 (핵심 흐름)

고객기사관리자접수 경로 3개 — 고객 전화를 받은 관리자가 콘솔 입력 / 기사가 앱에서 접수 / 관리자 모바일 접수. 현장·호기·고장구분(에러코드) 기록 알림 → 관리자: 고장 접수(긴급) / 갇힘·운행정지면 "중대 건" 별도 알림
관리자기사 지정 배정 기사 위치·거리·현재 작업을 보고 지정 (배정 시각 기록됨) 알림 → 그 기사: 고장이 배정되었습니다
기사접수한 기사 본인이 즉시 출동 기사가 접수하면 기본 배정=본인 — ETA까지 같이 넣으면 접수와 동시에 출동 처리(따로 응답 불필요). 이미 진행중 건이 있으면 기본 미배정
자동미배정 → 선착순 기사 전원에게 알림 — 먼저 잡는 사람이 담당 (DB가 한 명만 받아줌, 이중출동 불가) 알림 → 기사 전원: 미배정 고장 발생
자동재촉 (pg_cron, 평일 08:00~17:30만) 미배정 15분 지속 → 관리자에게 1회 / 배정 후 5분 미응답 → 기사+관리자에게 5분마다(최대 30분)
기사출동 응답 — 도착 예정시간(ETA) 입력 상태 진행중으로. 출발 위치 기록. 못 가면 "거부"(사유) → 미배정 환원 + 관리자 알림 문자 발송은 아직 없음(수동 안내)
기사현장 도착 도착 버튼 → 도착시각·위치 기록 (내 마지막 위치가 이 현장으로 갱신)
기사처리 완료 증상·원인·처리내용·사진 기록 → 완료. 부품 교체가 필요했으면 자재신청으로 이어짐
기사혼자 못 끝냄 (지원요청·운행정지) 에스컬레이션 → 미배정으로 복귀, 지원 갈 기사가 이어받음 알림 → 기사 전원: 지원 필요(미배정 복귀)
관리자사후 정정 (필요시) 재배정 — 잘못 배정·중복 출동 정정. 새 기사에겐 배정 알림, 이전 기사에겐 회수 알림
자동기록이 자산으로 처리 이력(증상→원인→처리)이 쌓임 — 통계·지식 아카이브(RAG)의 재료
이전 버전 (v0.1) 배정 분기가 "둘 중 하나(관리자 지정 / 미배정 선착순)"였음 → v0.2에서 "접수한 기사 본인이 즉시 출동" 경로 추가(기사 접수 시 기본 배정=본인, ETA 동시 입력 시 접수=출동).

흐름 3. 관리자의 하루

관리자대시보드 확인 (PC 콘솔 또는 모바일 관리자모드) 실시간 고장 현황(미배정·미응답 우선), 기사 위치 지도(관제), 출근 현황
관리자고장 대응 전화 접수 입력 → 배정 (거리·작업량 참고) → 미응답이면 재촉 알림이 자동으로 옴 → 필요시 재배정
관리자자재·견적·상비 처리 신청 확인 → 지급완료(사진·금액·담당) → 할일이 자동 생성돼 기사에게 감 / 견적 발행 → 고객 이메일 발송 알림 → 담당 기사: 지급 완료 — 수령 확인
관리자근태 관리 연차 신청 승인·반려(신청자에게 알림), 근무표. 최고관리자만: 당직표 생성·관리자 등록·비번 초기화
관리자비용청구 확인 기사가 올린 청구 검토. 최고관리자만: 무상 처리·가격 조정·삭제
관리자소통·설정 게시판 공지(전원 알림), 회사 알림 정책 27종(켤지·등급·받는 관리자 등급 — 개인 설정보다 우선, 테스트 발송 가능)
