# 구일 KV 검토 시안 02 — 2026-11-26

공유 주소: https://www.guil.kr/kv-preview/

클라이언트 콘티인 건물 → 승강로 최상층 → 상승하는 승강기 내부 → 구일 로고/문구를 검토하는 별도 페이지. 실제 홈페이지 KV, 메뉴, 사이트맵, 상담 API, 기존 앱에는 연결하거나 변경하지 않았다. 실제 구일 관리 건물이나 승강기 제품의 구조를 재현한 자료가 아니다.

## 동작

- 네이티브 세로 스크롤·트랙패드·모바일 스와이프로 전체 공간을 앞뒤로 이동한다. 휠 이벤트를 가로채지 않는다.
- 첫 외관은 이 시안의 3D 구도에 맞춰 제작한 AI 실사풍 이미지. 승강로에 호버하면 해당 부분의 이미지와 3D 외벽이 함께 투명해지고 내부 레일·카가 보인다. 포인터를 빼면 복구된다. 모바일에서는 표시를 눌러 투시를 켜고 끈다.
- 스크롤 시 사진에서 실시간 3D로 전환하며 최상층에 접근하고, 카메라가 내려가는 동안 카는 올라온다. 사진과 3D의 연결을 검토하는 하이브리드 시안이며 실사 영상이나 실제 건물 촬영본은 아니다.
- 첫 실내 구도는 스테인리스 문, 현재층 표시기, 14개 층수 버튼, 열림·닫힘·비상 버튼, 손잡이, 조명 중심이다. 큰 로고를 정면에 배치하지 않았다.
- 실제 3D 층수 버튼을 누르면 표시층/버튼 링이 변경된다. 문 열림·닫힘은 3D 조작반과 HTML 체험 버튼 모두 동작한다. 선택층으로 실제 운행하거나 비상 호출을 보내는 기능은 없다.
- 계속 스크롤하면 측벽의 작은 구일 명판으로 시선이 이동하고 배경이 사라진다. 실제 구일 로고, 회사명, 사용자 제공 문구 ‘최고의 기술력 · 최고의 서비스 · 합리적인 비용’이 나타난다.
- 하단 장면 선택은 선택적 바로가기다. 다시 보기, 안내창, 키보드 포커스/Enter, 네이티브 PageDown/PageUp을 제공한다.
- 모바일에서는 별도 카메라 구도와 시야각을 적용한다. OS 움직임 감소 설정에서는 보간/장식 애니메이션을 줄인다. 탭 비활성화/정지 상태에서 연속 렌더링을 중단한다.
- WebGL 초기화 실패 시 대체 화면과 다시 불러오기 버튼을 제공한다.

## 리소스와 빌드

- Three.js 0.170.0 공식 npm 배포본을 로컬 제공하며 MIT 라이선스를 동봉한다.
- 3D 모델, 금속 표면 텍스처, 조명/그림자는 코드로 작성했다. 기존 하늘·도시 WebP를 배경과 반사 환경으로 재사용한다.
- assets/guil-elevator-building-photoreal.webp: ImageGen으로 이 시안의 렌더 구도에서 생성한 전용 외관 이미지, 1672×941, 약 162 KiB. 실제 사례 사진이 아니다.
- 기존 실제 구일 로고 WebP를 재사용한다. Noto Sans KR은 Google Fonts에서 로드하며 시스템 글꼴 대체가 있다.
- 외부 모델 API, 영상 생성 API, 인증정보 또는 새 런타임 패키지는 사용하지 않는다.
- scripts/build.mjs의 기존 복사 단계가 public/kv-preview/로 복사한다. README는 배포하지 않는다.
- HTML에 noindex/nofollow/noarchive가 있으며 메인 메뉴와 사이트맵에서 링크하지 않는다. 공개 검토 링크이므로 비공개/암호 보호는 아니다.
- 나중에 제거할 때 이 디렉터리 및 build.mjs의 복사 단계와 사용하지 않는 cp import만 제거하면 된다. 메인 홈페이지와 공유하는 assets는 삭제하지 않는다.

## 확인

- JS 문법과 홈페이지 빌드 확인. 추가 전 공개 산출물 37개 해시와 비교해 변경 없음 확인.
- 데스크톱 호버 투시/복구, 네이티브 스크롤, 문 열림·닫힘, 실제 3D 층수 버튼, 엔딩 확인.
- 390px 모바일 외관/투시/실내 표시 및 가로 넘침 확인. 브라우저 콘솔 오류 없음.
- 특정 브라우저에서 버튼 포커스로 내부 컨테이너가 스크롤되는 문제는 overflow: clip으로 방지했다.
- 실제 기기별 GPU 성능과 모든 브라우저 호환성 측정을 대체하지 않는다.
