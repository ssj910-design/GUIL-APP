# 구일 KV 검토 시안 — 2026-11-26

공유 주소: https://www.guil.kr/kv-preview/

이 디렉터리는 클라이언트가 요청한 건물 → 승강로 → 상승하는 승강기 내부 → 로고/문구 콘티의 별도 인터랙티브 시안이다. 실제 홈페이지 KV에는 연결하지 않았으며 기존 홈페이지의 HTML/CSS/JS, 사이트맵, API, 앱 코드는 변경하지 않는다. 실제 제품 구조나 시공 사례를 재현한 모델이 아닌 자체 제작 개념 모델이다.

## 동작

- 첫 장면 자동 진입 후 대기. 건물 또는 파란 표시의 호버/키보드 포커스에 강조가 생긴다.
- 클릭/터치하면 외벽이 사라지고 승강로 최상층으로 접근한다.
- 다음 클릭에서 카메라는 하강하고 동일한 승강기 모델은 상승한다. 천장이 일시적으로 사라져 내부로 연결된다.
- 내부 로고 또는 표시를 클릭하면 로고로 접근하고 배경이 사라진다. 실제 구일 로고와 회사명, 사용자 제공 홍보 문구 ‘최고의 기술력 · 최고의 서비스 · 합리적인 비용’이 나타난다.
- 하단 4개 장면 선택, 다시 보기, 안내창, 키보드 버튼 사용을 제공한다. 이동 중 연속 입력은 차단한다.
- 모바일에서 시야각/카메라를 별도 조정한다. OS의 움직임 감소 설정에서는 긴 이동과 마우스 패럴렉스를 줄인다.
- WebGL 초기화 실패 시 대체 화면과 다시 불러오기 버튼을 제공한다. 탭이 숨겨지거나 장면이 정지하면 불필요한 연속 렌더링을 중단한다.

## 리소스와 빌드

- Three.js 0.170.0 공식 npm 배포본(로컬 제공), MIT 라이선스 동봉.
- 3D 모델/반사 환경/그림자는 코드로 생성한다. AI 생성 영상, 유료 모델, API, 인증정보를 사용하지 않는다.
- 기존 실제 구일 로고 WebP와 실패 화면용 건물 이미지를 재사용한다. 글꼴은 Google Fonts의 Noto Sans KR이며 로드 실패 시 시스템 글꼴을 사용한다.
- `scripts/build.mjs`의 마지막 `cp`가 이 디렉터리를 `public/kv-preview/`로 복사한다. README는 배포하지 않는다.
- HTML에 `noindex, nofollow, noarchive`; 메인 메뉴와 사이트맵에서 링크하지 않는다. 공개 검토 링크이므로 비공개/암호 보호 페이지는 아니다.
- 삭제 시 이 디렉터리 및 build.mjs의 해당 복사 단계와 사용하지 않게 되는 cp import만 제거하면 된다. 기존 로고/건물 자산은 실제 홈페이지에서도 사용하므로 삭제하지 않는다.

## 확인

- 빌드와 JS 문법 검사 통과. 추가 전 공개 산출물 37개의 해시와 비교해 모두 동일함을 확인.
- 데스크톱에서 4단계 이동, 실내 3D 로고 직접 호버/클릭, 장면 선택, 엔딩, 재시작, 안내창/Escape, Enter 키 동작 확인.
- 390px 모바일 각 장면 표시 및 터치 대체 버튼 확인. 320px에서도 실내 버튼의 화면 내 배치와 가로 넘침 없음 확인.
- 확인한 브라우저 콘솔 오류 없음. 실제 기기별 GPU 성능이나 모든 브라우저 호환성을 보증하는 측정은 아님.
