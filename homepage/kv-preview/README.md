# 구일 KV 검토 시안 03 — 2026-11-26

공유 주소: https://www.guil.kr/kv-preview/

## 범위

이 디렉터리만 수정한다. 실제 홈페이지의 KV·메뉴·HTML·CSS·JS·사이트맵·상담 API 및 기존 앱은 변경하지 않는다. AI 실사풍 이미지에 레이어 모션을 적용한 별도 검토 시안이다. 실제 관리 건물이나 제품의 촬영본, 자유 시점의 3D 공간, 실제 승강기 운행을 재현하는 시뮬레이터는 아니다.

## 연출

- 기존 외관 이미지는 유지한다. 승강로 호버/키보드 포커스 시 사진 위의 제한된 영역으로 실사풍 승강로가 드러나고 마우스를 빼면 복원된다. 모바일은 터치로 고정/해제한다.
- 스크롤을 가로채지 않는 네이티브 세로 이동이다. 스크롤 위치에 따라 건물 확대 → 겹치는 디졸브 → 실사풍 승강로 확대 → 실내로 이어진다. 역스크롤도 동작한다.
- 이전 시안의 단순 3D 모형이 전환 중에 노출되는 구간을 없앴다. 콘크리트·레일·로프·카 지붕과 스테인리스 실내의 사진 톤을 연결한다.
- 실내 사진은 문, 현재층 표시기, 12개 층수 버튼, 문 열림/닫힘·알람 버튼, 손잡이, 조명으로 구성한다. 내벽에 구일 명판이나 로고는 없다.
- 사진의 좌우 문짝만 SVG 클립으로 분리하고 실제 문틀 뒤로 이동시킨다. 문 너머의 HTML 구일 로고가 드러나며, 열린 문을 향해 확대해 브랜드 화면으로 이어진다. 로고는 이미지에 생성하지 않고 기존 실제 로고 WebP를 사용한다.
- 문은 스크롤로 자동 열리고 역스크롤로 닫힌다. 실내 체험 구간의 별도 버튼과 사진 조작반에서도 열고 닫을 수 있다. 수동으로 열고 스크롤을 이어가면 다시 닫히는 튐 없이 엔딩으로 연결된다.
- 층수 버튼은 표시층과 선택 강조만 바꾸며 실제 운행·비상 호출을 전송하지 않는다.
- 마지막에 사용자 지정 문구 ‘최고의 기술력 · 최고의 서비스 · 합리적인 비용’이 나타난다. 장면 선택·재시작·안내창 및 키보드 사용을 유지한다.

## 리소스와 성능

- assets/guil-elevator-building-photoreal.webp: 이전 시안 외관 그대로 사용.
- assets/guil-elevator-hoistway-photoreal-v3.webp: ImageGen 내장 도구로 생성한 승강로, 1672×941, WebP.
- assets/guil-elevator-cabin-photoreal-v3.webp: ImageGen 내장 도구로 생성한 닫힌 문 실내, 1672×941, WebP. 사진 원본은 변형하지 않고 CSS/SVG로 표시 영역과 문짝만 제어한다.
- 모든 장면 이미지를 디코딩한 뒤 체험을 활성화해 전환 중 미로딩 화면을 방지한다. 실패하면 다시 불러오기 화면을 표시한다.
- 런타임은 DOM/CSS/SVG이며 WebGL, 유료 API, 새 외부 패키지, 환경 변수는 필요하지 않다. 기존 vendor/Three.js 파일은 이전 시안 이력용으로 남아 있으나 이 버전에서 요청하거나 실행하지 않는다.
- 정지 상태/숨긴 탭에서는 rAF를 계속 실행하지 않는다. OS 움직임 감소 설정에서는 확대 이동과 지연 보간을 줄인다.
- 모바일은 실내 문과 조작반이 함께 보이는 별도 프레이밍을 사용하며 문 열림 영역을 주변 흐림 배경이 가리지 않도록 마스킹한다.

## 빌드 및 제거

기존 scripts/build.mjs의 복사 단계가 public/kv-preview/로 복사한다. README는 배포되지 않는다. noindex/nofollow/noarchive를 유지하고 메뉴/사이트맵에서 연결하지 않는다. 공개 링크이며 비공개 인증 페이지는 아니다.

추후 삭제할 때 이 디렉터리와 build.mjs의 복사 단계 및 사용하지 않는 cp import만 제거하면 된다. 홈페이지에서 공유하는 상위 assets는 삭제하지 않는다.
