# 구일 KV 검토 시안 17 — 2026-11-27

공유 주소: https://www.guil.kr/kv-preview/

## 범위

이 디렉터리만 수정한다. 실제 홈페이지 KV, 메뉴, HTML, CSS, JS, 사이트맵, 상담 API 및 기존 앱은 변경하지 않는다. 실사풍 이미지와 3D 공간을 결합한 별도 검토 시안이며 실제 건물 설계나 승강기 운행을 재현하는 시뮬레이터는 아니다.

- 하드웨어는 반복 부품을 인스턴싱했다. 지붕은 24개 묶음, 벽 고정부·트레이·배관은 12개 묶음으로 그린다. 승강장 보강재는 실제 층 높이에 따라 geometry를 공유한다.
- 모든 지붕 부품은 기존 카 지붕 범위 안에 있으며, 기존 지붕 투명도와 함께 사라지고 복원된다. 건물·카메라 경로와 시야각·1초 대기를 포함한 20초·로고·UI는 변경하지 않았다.

- 사용자가 제공한 승강로 사진 4장을 재질 참고로 삼았다. 사진 자체를 사이트 자산에 복사하거나 워터마크를 제거하지 않았다. 형상은 기존 시안 그대로이며 특정 사진 속 설비를 재현한 구조도는 아니다.
- 콘크리트를 밝은 회색으로 정리하고 1.22×2.44m 거푸집 이음선, 작은 타이 구멍, 패널별 미세 색차·약한 물자국을 셰이더에 추가했다. 세부 PBR 결은 1.4m 단위로 반복하며, 수평 면에는 벽체용 패널·구멍을 그리지 않는다. 화면 픽셀 변화량을 사용해 먼 이음선의 반짝임을 줄인다. 추가 텍스처 다운로드나 변위는 없다.
- 레일의 연마면과 측면의 밝기·거칠기 차이를 조정했고, 지붕은 무광 회색 철판에 가까운 반사로 바꿨다. 실내 스테인리스는 v15를 유지한다.
- 건물, 모델 치수, 카메라 경로와 시야각, 1초 대기를 포함한 전체 20초, UI와 로고는 유지한다.

- 지붕·레일·실내 스테인리스·승강로 콘크리트에 색상/노멀/거칠기를 분리한 CC0 PBR 텍스처를 적용했다. 새 WebP 9개는 총 517,852바이트다. 공통 조명·건물 및 모델 형상·카메라 경로·로고 연출·UI·20초 시간 곡선은 그대로다.
- 콘크리트는 거푸집 결과 잔기공을 더하되 큰 얼룩의 명암은 줄인다. 지붕은 요철을 얕게 하고, 판금 표면과 접힌 가장자리가 서로 다른 반사를 낸다. 레일의 연마 결과 노멀 방향을 길이 방향으로 맞추고 은색 밝기를 유지한다.
- 실내는 기존 사진의 문·층수 표시·조작반 위치를 유지하면서 PBR 미세 결, 거칠기, 시점에 따른 환경 반사를 합성한다. 표시판과 조작반 영역은 반사 합성에서 제외해 글자 선명도를 유지한다. 사진 투영과 반사를 결합한 방식이며 완전한 실측 재구성은 아니다.
- 준비 완료 후 1초 대기 + 약 19초 이동 = 전체 20초. 스크롤·터치 시 수동 전환과 로고에서 정지는 그대로다.

## 연출

- v14 모바일 보정: 건물 진입 시 32.42m 층 바닥 위를 먼저 통과한 다음 승강로 안에서 아래로 시선을 돌린다. 모바일에서 바닥 면이 화면을 막던 구간을 제거했다. 전체 20초 시간 곡선은 유지한다.
- 실내 기준 사진의 수직 시야각을 50°로 맞춰 상단 층수 표시가 천장 아래에 들어오도록 한다. 원본 사진의 숫자 영역은 가리고, 문틀보다 앞에 별도 표시판과 얕은 테두리를 배치한다. 숫자와 벡터 화살표를 한 겹으로 렌더링하며, 조작반 터치 위치도 실제 앞면으로 맞춘다. 실내 시야각은 화면 폭 기준의 급격한 전환 대신 화면 비율에 연속적으로 맞춘다.
- 세로 화면에서 원본 사진 밖으로 드러나는 천장·바닥에는 금속 패널 선·간접 조명과 석재 타일 질감을 이어 그린다. 화면 회전 때 현재 장면의 스크롤 비율을 다시 맞춰 장면이 끝으로 넘어가지 않도록 한다.
- 승강기 지붕의 얇은 분할 금속판·접힌 가장자리·점검 덮개·인스턴싱한 육각 볼트를 유지한다. 불투명할 때는 정상 깊이 처리를 사용하고, 카메라 진입 구간에서만 투명 처리한다. v15에서 표면 재질만 교체했다.

- 실사풍 건물 외관과 3D 공간을 같은 원근 기준으로 맞춘다. 사진의 낮은 눈높이를 8.8 좌표로 잡고 수직 렌즈 시프트를 적용해 수평면의 기울기와 수직선을 함께 보정한다. 화면 비율 변경은 카메라 위치 대신 렌즈 시프트와 시야각으로 처리한다. 진입 중 렌즈 시프트는 점진적으로 해제한다.
- 호버 투시는 사진에서 측정한 4열 × 11행의 유리창만 드러낸다. 창틀과 층 경계, 입구·캐노피·로비는 원본 사진을 유지한다. 내부를 어둡게 하고 유리 반사를 일부 남겨 승강로가 외벽 뒤에 보이도록 한다. 모바일은 터치로 고정/해제한다.
- 사진의 창틀 위치와 각 층 경계를 -31°의 공통 공간으로 역투영한다. 임의의 동일 간격 대신 측정한 층 높이를 승강로의 문·레일 고정대·바닥 연결부에 함께 사용한다. 바닥 연결부는 외벽에서 코어 앞까지만 이어져 승강로를 막지 않는다. 진입 중 창별 투시가 연속된 3D 개구부로 바뀌고 내부 조명은 기존 톤으로 복원된다.
- 네이티브 세로 스크롤 위치가 한 카메라의 연속 경로를 제어한다. 사진끼리 디졸브하지 않고 건물 외벽을 통과해 승강로 상부로 진입한다. 카메라가 진입 중 사선 좌표계로 합류하여 승강로 중심에 정렬되며, 승강로 자체를 회전시키지 않는다. 전체 스크롤 길이는 780svh이며 진입에 더 많은 구간을 배정한다. 건물 진입은 약 166→238vh, 실내 진입은 약 109→163vh로 늘렸다. 가속·감속 보간과 초당 진행 속도 제한으로 큰 휠 입력이나 장면 바로가기에서도 진입이 급해지지 않도록 한다.
- 카메라는 하강하고 승강기는 상승한다. 벽체, 층별 문 뒷면, T형 레일, 브래킷, 고정 볼트, 로프, 배선 트레이, 균형추, 상부 구동기를 같은 공간에 구성한다.
- 승강기 천장은 고정한 채 표면과 상부 설비만 서서히 투명해진다. 카메라가 통과한 뒤 실내 눈높이에 도착하면 천장이 복원된다. 해치 개폐와 수평 이동은 제거했다. 외벽·레일·문은 이 투명 효과의 영향을 받지 않는다. 역스크롤에도 같은 경로와 투명도를 적용한다.
- 실내도 3D 벽, 바닥, 천장, 문으로 구성한다. 기존 실사풍 이미지의 질감을 투영해 스테인리스 문과 층수 표시, 조작반, 손잡이를 유지한다. 사진에 없는 시점은 금속 재질로 보완하며 자유 시점의 완전한 실사 재구성은 아니다.
- 콘크리트는 1.4m 단위 UV와 OpenGL 노멀맵·거칠기맵을 사용한다. 긴 벽에서 늘어나지 않게 공간 기준 UV를 적용하고, 밉맵과 최대 8배 이방성 필터링으로 먼 표면의 반짝임을 줄인다. 레일은 기존 T형 단면의 얇은 모따기를 유지하고 연마면·측면에 서로 다른 금속 반사를 적용한다. 와이어는 별도 무광 강철 재질을 유지한다. 기존의 부드러운 조명 반사 환경과 1024px 그림자는 변경하지 않았다.
- 실내 사진의 청색·회색 덮개를 줄이고 미세 금속 결과 보는 각도에 따른 약한 반사를 더한다. 문틀에는 얇은 스테인리스 입체 마감이 있다. 조작반과 문 위치, 텍스처 투영 좌표는 유지한다.
- 좌우 문짝이 문틀 뒤로 열리면서 실제 구일 로고가 보인다. 로고가 화면 중앙에서 최종 크기의 2.5배(모바일 2.3배)로 먼저 나타나 잠시 머문다. 1.0~2.15초에 축소·이동을 마치고, 회사명은 2.3~3.25초에 오른쪽으로 펼쳐진다. 이동과 회사명 등장을 겹치지 않는다. 후속 문구는 3.35초 이후 나타난다. 이 순서는 문 열림 후 경과 시간으로 진행하며, 문을 닫거나 처음으로 돌아가면 초기화된다. 카메라가 열린 문을 통과해 밝은 브랜드 화면으로 이어진다. 실내 벽면에 로고를 붙이지 않는다.
- 문은 스크롤과 별도 버튼/실내 조작반으로 열고 닫을 수 있다. 층수 선택은 표시기만 바꾸며 실제 운행이나 비상 호출을 전송하지 않는다.
- 역스크롤, 장면 바로가기, 재시작, 안내창과 키보드 조작을 유지한다.
- 준비 완료 후 건물을 1초 유지하고, 약 19초에 걸쳐 한 번만 자동으로 이동한 뒤 로고에서 정지한다. 전체 20초 중 건물 진입에 7.2초를 배정하며, 이후 승강로 하강·실내 도착·문 열림·로고 이동은 속도가 연속적인 별도 시간 곡선을 사용한다. 자동재생은 실제 스크롤 위치를 카메라와 계속 맞춘다. 휠·터치·포인터 누름·이동 키·장면 선택 시 현재 위치에서 수동 조작으로 전환하며 자동으로 재개하지 않는다. 다시 보기를 누르면 건물로 돌아가 새로 재생한다.
- 숨긴 탭에서는 시간과 렌더링이 멈춘다. OS 움직임 감소 설정이나 이미 스크롤한 위치에서 새로고침한 경우 자동재생하지 않는다. 승인된 로고 등장·축소·이동 순서와 창틀 투시는 그대로 유지한다.

## 구현과 리소스

- world.js: 하나의 Three.js 장면, 카메라, 3D 승강로와 실내, 외벽 투시, 실제 문 이동.
- hardware.js: 지붕 프레임·설비와 승강로 브래킷·배선 트레이. 절곡 단면·둥근 모서리·체결부와 인스턴싱 묶음.
- preview.js: 스크롤, 호버/터치, 문 조작, UI, 재시작과 수명 관리.
- motion.js: 구간별 스크롤 배분, 장면 바로가기의 역변환, 감쇠·속도 제한, 자동재생 시간과 경로.
- assets/guil-elevator-building-photoreal.webp: 기존 건물 외관.
- assets/materials/: 현재 사용하는 PBR WebP 9개. 아래 출처와 변환 기록 참고.
- assets/guil-elevator-shaft-concrete.webp: 이전 버전 검토 이력용 생성 질감. 현재 페이지에서는 요청하지 않는다.
- assets/guil-elevator-cabin-photoreal-v3.webp: 기존 실사풍 실내 질감. 원본 이미지는 변경하지 않는다.
- assets/guil-elevator-hoistway-photoreal-v3.webp: 이전 버전 검토 이력용이며 현재 페이지에서 요청하지 않는다.
- vendor/three.module.min.js: 기존 로컬 Three.js 0.170.0, MIT. CDN/API/환경 변수 없이 동작한다.
- 필요한 텍스처가 준비된 후 시작한다. WebGL/로딩 실패 시 다시 불러오기 안내를 제공한다.
- 픽셀 비율은 최대 1.8, 반복 볼트는 인스턴싱을 사용한다. 정지 시점과 숨긴 탭에서는 계속 렌더링하지 않는다.
- OS 움직임 감소 설정에서는 스크롤 바로가기와 지연 보간을 즉시 반영한다. 스크롤에 따른 공간 이동 자체는 유지한다.
- 모바일에는 별도 시야각과 UI 배치를 적용한다.

## 빌드 및 제거

기존 scripts/build.mjs가 public/kv-preview/로 복사한다. README는 배포하지 않는다. noindex/nofollow/noarchive를 유지하고 메뉴와 사이트맵에서 연결하지 않는다. 공개 검토 링크이며 인증된 비공개 페이지는 아니다.
