# 구일 KV 검토 시안 07 — 2026-11-26

공유 주소: https://www.guil.kr/kv-preview/

## 범위

이 디렉터리만 수정한다. 실제 홈페이지 KV, 메뉴, HTML, CSS, JS, 사이트맵, 상담 API 및 기존 앱은 변경하지 않는다. 실사풍 이미지와 3D 공간을 결합한 별도 검토 시안이며 실제 건물 설계나 승강기 운행을 재현하는 시뮬레이터는 아니다.

## 연출

- 실사풍 건물 외관을 3D 공간의 전면에 배치한다. 건물 사진의 사선 방향에 맞춰 승강로·승강기·설비를 하나의 고정된 좌표계에 배치한다. 호버/키보드 포커스로 외벽 일부가 투명해지면 그 뒤의 실제 3D 승강로가 보인다. 투시 영역은 외벽 창호에 고정한다. 승강로는 이전 위치에서 깊이 4.8, 옆으로 1.2 좌표만큼 건물 안쪽으로 이동하고, 외벽의 구멍과 내부 구조 사이에 네 면의 벽 두께와 안쪽 음영을 연결한다. 호버 시 유리 외벽의 반사와 앞쪽 층 경계를 일부 남긴다. 모바일은 터치로 고정/해제한다. 승강로 폭·깊이는 이전 대비 76%, 차체 높이는 72%로 보정해 창호 간격과 층고에 맞춘다. 중앙 위치와 실내 카메라 높이·시야각도 함께 보정한다.
- 네이티브 세로 스크롤 위치가 한 카메라의 연속 경로를 제어한다. 사진끼리 디졸브하지 않고 건물 외벽을 통과해 승강로 상부로 진입한다. 카메라가 진입 중 사선 좌표계로 합류하여 승강로 중심에 정렬되며, 승강로 자체를 회전시키지 않는다. 전체 스크롤 길이는 780svh이며 진입에 더 많은 구간을 배정한다. 건물 진입은 약 166→238vh, 실내 진입은 약 109→163vh로 늘렸다. 가속·감속 보간과 초당 진행 속도 제한으로 큰 휠 입력이나 장면 바로가기에서도 진입이 급해지지 않도록 한다.
- 카메라는 하강하고 승강기는 상승한다. 벽체, 층별 문 뒷면, T형 레일, 브래킷, 고정 볼트, 로프, 배선 트레이, 균형추, 상부 구동기를 같은 공간에 구성한다.
- 승강기 천장은 고정한 채 표면과 상부 설비만 서서히 투명해진다. 카메라가 통과한 뒤 실내 눈높이에 도착하면 천장이 복원된다. 해치 개폐와 수평 이동은 제거했다. 외벽·레일·문은 이 투명 효과의 영향을 받지 않는다. 역스크롤에도 같은 경로와 투명도를 적용한다.
- 실내도 3D 벽, 바닥, 천장, 문으로 구성한다. 기존 실사풍 이미지의 질감을 투영해 스테인리스 문과 층수 표시, 조작반, 손잡이를 유지한다. 사진에 없는 시점은 금속 재질로 보완하며 자유 시점의 완전한 실사 재구성은 아니다.
- 재질의 미세 노이즈와 범프 강도를 줄이고 금속의 거칠기를 높였다. 주변광을 보강하고 직접광을 낮춰 표면 대비를 완화한다. 실내 사진 투영의 색 대비도 소폭 낮추되 조작반과 문 디테일은 유지한다.
- 좌우 문짝이 문틀 뒤로 열리면서 실제 구일 로고가 보인다. 로고가 중앙에서 먼저 서서히 나타난 뒤 왼쪽으로 자리를 잡으며 회사명이 옆으로 펼쳐진다. 후속 문구는 그 뒤에 나타난다. 이 순서는 문 열림 후 경과 시간으로 진행하며, 문을 닫거나 처음으로 돌아가면 초기화된다. 카메라가 열린 문을 통과해 밝은 브랜드 화면으로 이어진다. 실내 벽면에 로고를 붙이지 않는다.
- 문은 스크롤과 별도 버튼/실내 조작반으로 열고 닫을 수 있다. 층수 선택은 표시기만 바꾸며 실제 운행이나 비상 호출을 전송하지 않는다.
- 역스크롤, 장면 바로가기, 재시작, 안내창과 키보드 조작을 유지한다.

## 구현과 리소스

- world.js: 하나의 Three.js 장면, 카메라, 3D 승강로와 실내, 외벽 투시, 실제 문 이동.
- preview.js: 스크롤, 호버/터치, 문 조작, UI, 재시작과 수명 관리.
- motion.js: 구간별 스크롤 배분, 장면 바로가기의 역변환, 감쇠와 속도 제한.
- assets/guil-elevator-building-photoreal.webp: 기존 건물 외관.
- assets/guil-elevator-cabin-photoreal-v3.webp: 기존 실사풍 실내 질감. 원본 이미지는 변경하지 않는다.
- assets/guil-elevator-hoistway-photoreal-v3.webp: 이전 버전 검토 이력용이며 현재 페이지에서 요청하지 않는다.
- vendor/three.module.min.js: 기존 로컬 Three.js 0.170.0, MIT. CDN/API/환경 변수 없이 동작한다.
- 필요한 텍스처가 준비된 후 시작한다. WebGL/로딩 실패 시 다시 불러오기 안내를 제공한다.
- 픽셀 비율은 최대 1.8, 반복 볼트는 인스턴싱을 사용한다. 정지 시점과 숨긴 탭에서는 계속 렌더링하지 않는다.
- OS 움직임 감소 설정에서는 스크롤 바로가기와 지연 보간을 즉시 반영한다. 스크롤에 따른 공간 이동 자체는 유지한다.
- 모바일에는 별도 시야각과 UI 배치를 적용한다.

## 빌드 및 제거

기존 scripts/build.mjs가 public/kv-preview/로 복사한다. README는 배포하지 않는다. noindex/nofollow/noarchive를 유지하고 메뉴와 사이트맵에서 연결하지 않는다. 공개 검토 링크이며 인증된 비공개 페이지는 아니다.

추후 삭제할 때 이 디렉터리와 build.mjs의 복사 단계 및 사용하지 않는 cp import만 제거한다. 홈페이지에서 공유하는 상위 assets는 삭제하지 않는다.

## 검증

JS 문법과 정적 빌드 통과, 기존 배포 파일 37개의 해시 불변을 확인했다. 스크롤 매핑의 단조 증가·역변환과 20/60/120fps에서 정방향·역방향 수렴 및 최대 속도를 수치 검증했다. 데스크톱/390px 모바일의 건물 투시, 승강로 이동, 천장 투명도 변화와 복원, 문 열림/닫힘, 브랜드 엔딩과 재시작을 브라우저에서 확인했다. 로고가 표시되는 동안 회사명 투명도가 0인 첫 구간과, 이후 회사명이 완전히 표시되는 상태를 확인했다. 실제 모든 장치 및 브라우저 조합에 대한 성능 측정은 아니다.
